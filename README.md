# Manuel Bomheker

Sitio web personal y landing profesional de Manuel Bomheker.

## Publicacion

El archivo principal del sitio es `index.html`.

Para publicar en Cloudflare Pages:

1. Conectar este repositorio desde Cloudflare Pages.
2. Usar la rama `main`.
3. Dejar el comando de build vacio.
4. Usar `/` como directorio de salida.
